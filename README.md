# 📌 Project Overview

Java 21 is the latest **Long-Term Support (LTS)** release and is rapidly becoming the preferred version for enterprise software development. Modern automation frameworks increasingly benefit from Java 21’s language enhancements, improved collections, cleaner syntax, and better concurrency support.

This repository demonstrates **practical Java 21 features** through easy-to-understand examples that automation engineers, SDETs, and Java developers can directly apply while building scalable automation frameworks.

Whether you're preparing for technical interviews or modernizing enterprise automation projects, this repository provides hands-on examples of Java 21 features with real-world relevance.

## ✅ Sequenced Collections *(Permanent)*

Introduces a consistent API for ordered collections.

Benefits:

- Retrieve first element
- Retrieve last element
- Reverse collections easily
- Cleaner collection handling

**Example File**

```
SequencedCollection.java
```

Allows ignoring unused variables, reducing unnecessary code.

Useful when:

- Cleaner exception handling
